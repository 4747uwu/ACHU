DICOM

Shown on this workstation and written to the log. It is not enforced: a modality may use any destination AE title and will still connect, so a mismatch here never blocks a study. What must match on the modality are the IP address and port. DICOM C-STORE SCP listener port. Requires sender restart to take effect. Default: 8888. Quiet period before a series is considered complete and queued for transfer. Default: 5s. Automatically overridden when the modality reports the expected instance count.

Storage & retention

Delivered studies are auto-deleted from this workstation after the retention window. Failed studies are never auto-deleted.

JPEG 2000 Compression

Transcode DICOM files to JPEG 2000 Lossy before uploading. Reduces bandwidth without perceptible loss for most modalities. Requires gdcmconv.exe alongside the sender binary. Skip files already encoded as JPEG 2000 Lossy (prevents quality degradation from re-compression). Leave on unless you need to re-encode with a different ratio.

Secure DICOM

TLS and plaintext share the listening port — each connection is identified by its first byte — so a modality configured for Secure DICOM and one sending plaintext both work without any change here. A self-signed certificate is generated on first run and reused thereafter, so a modality that pins it keeps working across upgrades.

JPEG 2000 Lossless (.90)

Re-encode images to JPEG 2000 lossless before upload. The result is pixel-for-pixel identical to what the modality sent — typically 40–60% smaller — and nothing is discarded, so no clinical detail is lost. Off by default: studies are forwarded exactly as the modality sent them unless you turn this on. Leave files that already carry compressed pixel data alone. Re-encoding them costs CPU for almost no saving, and an already-lossy image cannot be repaired by storing it losslessly.

Network Resilience

When the network drops mid-upload, automatically retry without counting against the failure limit. Studies retry indefinitely until delivered. Track which DICOM instances were already delivered. On retry after a network failure, only the remaining instances are re-sent — not the full series. Probe the receiver every 30 seconds. Pause uploads automatically when the peer is unreachable and resume when it comes back — prevents wasted retry attempts during outages.
